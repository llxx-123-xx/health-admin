# 个人健康管理系统 - 运营管理后台

基于 Vue 3 + Spring Boot 3 开发的全栈 B 端运营平台。

## ✨ 核心功能
- **RBAC 权限控制**：基于 Spring Security + JWT 实现用户-角色-菜单模型，前端通过 Vue Router 守卫实现不同角色的菜单隔离与接口越权拦截。
- **高频操作防重**：针对“批量禁用用户”等高并发写操作，引入 Redis 的 `SETNX` 命令实现分布式接口幂等性校验，有效防止网络延迟导致的重复提交。
- **敏感数据脱敏**：在后端通过 Jackson 自定义序列化注解，对手机号等用户隐私字段实现出库前的自动掩码脱敏（如 `138****1234`）。
- **多条件复杂检索**：基于 MyBatis-Plus 的 Lambda 条件构造器，实现了基于时间范围、状态、关键字的动态 SQL 组合查询与分页。
